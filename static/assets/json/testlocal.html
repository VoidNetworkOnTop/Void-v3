Security First Design

This renderer prioritizes security over perfect site reproduction. Some interactive elements might not work due to security restrictions.

  • Secure by default: JavaScript disabled, HTML sanitization enabled
  • Content isolation: All content is rendered in a secure sandbox
  • Resource protection: Dangerous elements and scripts are filtered
